My thesis puts these systems to the test empirically, asking one thing: when an LLM solves a problem, is it reasoning its way there, or just remembering an answer it saw during training?

Lately, my week looks like:

- Building agentic AI systems for automated program repair at Grimlock Consulting 🤖
- Finishing my M.A.Sc. thesis at York University on how robust LLM software-engineering agents really are 🎓

### Cognitive Evaluation of LLMs for Test Case Generation [2025]

<img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/python/python-original.svg" height="24" alt="Python" /> <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/docker/docker-original.svg" height="24" alt="Docker" />

A cognitive evaluation framework (adapted from Bloom's Taxonomy) for LLMs generating test cases from bug reports. It tests how the models hold up when the report is rephrased, translated or has its identifiers masked, and a separate analysis shows which parts of a bug report the models actually rely on.

The whole story is at [arxiv.org/abs/2510.05365](https://arxiv.org/abs/2510.05365).

<img src="assets/rule.svg" width="100%" />
